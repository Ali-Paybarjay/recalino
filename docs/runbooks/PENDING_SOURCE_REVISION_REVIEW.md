# انتخاب نسخهٔ محتوای منبع — پیگیری بازبینی 2026-10-06

در بازبینی پیش از push، تغییر نسخهٔ انتخاب‌شدهٔ محتوا از مسیر PATCH موجود بررسی شد. رابط فعلی SourcesView فقط نمایش متن استخراج‌شده را دارد و انتخاب یا اصلاح revision محتوا را ارائه نمی‌کند؛ این یادداشت مجوز ساخت آن قابلیت نیست.

Fingerprint فعلی انتخاب منابع در `packages/core/src/proc/selection.ts` فقط انتخاب فایل/نقش/بازه را مدل می‌کند. `ProcessingView.tsx` برای حفظ نتیجه پس از استخراج خودکار، آن را بر `sourcesVersion` ترجیح می‌دهد. انتخاب صریح نسخهٔ دیگری با API می‌تواند محتوای snapshot را عوض کند، ولی fingerprint را عوض نکند؛ در نتیجه پیشنهاد reprocess پس از نتیجهٔ آماده در UI دیده نشود.

پیش از افزودن رابط انتخاب یا اصلاح نسخهٔ محتوا، تغییر صریح کاربر باید از تغییر نسخهٔ استخراج خودکار جدا مدل شود. صرف افزودن `contentVersionId` به fingerprint صحیح نیست، چون استخراج معمول می‌تواند نتیجهٔ تازه را بلافاصله stale جلوه دهد. بررسی لازم: اصلاح صریح کاربر reprocess را آشکار کند، استخراج خودکار این کار را نکند و snapshot/تاریخچهٔ اجرای قبلی تغییرناپذیر بمانند.
