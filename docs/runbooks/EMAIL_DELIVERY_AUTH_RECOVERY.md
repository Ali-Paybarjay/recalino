# بازیابی خطای ورود Gmail

این راهنما برای فرستندهٔ Gmail مصوب [D42](../PRODUCT_DECISIONS_LOG.md) است. `smtp_authentication_rejected` یعنی Gmail ورود SMTP را رد کرده و آن تلاش، پیام را برای ارسال نپذیرفته است. «تنظیم‌شده» در پنل فقط وجود تنظیمات را نشان می‌دهد؛ پذیرش ایمیل یا رسیدن به Inbox را تأیید نمی‌کند.

## اصلاح اتصال

1. صاحب حساب `recalino.pilot@gmail.com` در [App Passwords گوگل](https://myaccount.google.com/apppasswords) با همین حساب وارد شود و تأیید هویت خواسته‌شده را انجام دهد.
2. یک App Password تازه برای Recalino بسازد. رمز ورود عادی Gmail برای SMTP استفاده نشود. رمز در چت، فایل، Git، لاگ یا تصویر بررسی قرار نگیرد.
3. در پروژهٔ `recalino` در Vercel، **Settings → Environment Variables**، مقدار `RECALINO_GMAIL_APP_PASSWORD` را فقط برای **Production** جایگزین و ذخیره کند. مقدار باید رمز تازهٔ همین حساب باشد؛ فاصله‌های نمایشی رمز گوگل حذف شوند.
4. یک deployment تازهٔ Production منتشر شود. تغییر متغیر محیطی روی deployment قبلی اعمال نمی‌شود. تنظیمات عمومی فرستنده و حساب نیز باید با Gmail پایلوت یکسان بمانند.
5. وضعیت فعلی همان پیام قبلاً تأییدشده را دوباره بخوانید. اگر همچنان `failed` با خطای ورود است، از **تلاش مجدد** همان ردیف استفاده کنید؛ محتوای تأییدشده و گیرنده تغییر نکنند. برای این بازیابی پیش‌نویس تازه نسازید.

## بررسی نتیجه

پنل وضعیت `queued` و `sending` را با درخواست فقط‌خواندنی به‌روز می‌کند. این بررسی ایمیل دیگری ارسال نمی‌کند. پس از توقف بررسی خودکار، دکمهٔ تازه‌سازی وضعیت قابل استفاده است؛ خطای شبکه نتیجهٔ شناخته‌شدهٔ قبلی را پاک نمی‌کند.

- `failed`: پیام پذیرفته نشده است؛ کد خطا و راهنمای پنل را بررسی کنید. تلاش مجدد پس از اصلاح علت ممکن است.
- `sent`: Gmail پیام را پذیرفته و مرجع ارسال ثبت شده است. دریافت Inbox هنوز باید توسط گیرنده بررسی شود؛ پوشهٔ Spam و نشانی گیرنده نیز بررسی شوند.
- `unknown`: نتیجهٔ پذیرش نامشخص است. از تلاش مجدد یا ساخت ایمیل مشابه خودداری کنید؛ ابتدا شواهد Sent، receipt و گیرنده مطابق [راهنمای پنل](ADMIN_PANEL.md) تطبیق و نتیجه reconcile شود.

در گزارش عملیات فقط وضعیت، کد خطا، زمان و وجود receipt ثبت شود؛ متن ایمیل، نشانی مشتری، رمز و توکن ثبت نشوند. این نسخه webhook تحویل یا bounce tracking ندارد.
