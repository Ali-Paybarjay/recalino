## تغییر نسبت به Claude Design

تحویل قبلی از ابتدا جریان کامل MVP، منشأ محتوا، RTL، dark و دسترس‌پذیری را طراحی کرده بود. تغییر تازه، زبان بصری هماهنگ‌تر با مطالعه، سلسله‌مراتب روشن‌تر، فرم‌های کوتاه‌تر با Cancel مستقل، جزوه با عرض خواندن محدود، مسیرهای روشن ادامه/خطا و نمونهٔ تعاملی متصل برای همهٔ صفحه‌هاست.

## مرز نمونه با محصول

بک‌اند فعلی ACC/PLT است. ORG/REC/SRC/PROC/LKM/CARD/SRS هنوز سرویس محصولی کامل ندارند؛ این بازطراحی آن سرویس‌ها را کامل‌شده معرفی نمی‌کند:

- `/preview/[screen]` دادهٔ مصنوعی، نوار دائمی «Sample workspace — changes affect this preview only» و Reset sample دارد.
- کلاس، فایل، جزوه، کارت و مرور در state محلی تعامل دارند. تغییرها ماندگار و قابل بازنشانی‌اند؛ state ذخیره‌شده پیش از استفاده اعتبارسنجی می‌شود.
- منابع، transcript و تاریخچهٔ جزوه برای هر کلاس جداست. ساخت کلاس داده‌های کلاس دیگری را کپی نمی‌کند؛ کارت‌های مرور در مجموعهٔ همهٔ کلاس‌ها باقی می‌مانند.
- Pause/Resume زمان و عکس‌های نمونه را حفظ می‌کند. مدت صوت/PDF انتخاب‌شده تا تأیید metadata وارد برآورد نمی‌شود؛ ورودی هر job ثابت است و retry فقط منبع ناموفق را بدون مصرف دوبارهٔ سهمیهٔ نمونه تکرار می‌کند.
- فایل آپلود، میکروفون/دوربین فعال، AI فراخوانی، هزینه/سهمیهٔ واقعی کم و برنامهٔ FSRS محاسبه نمی‌شود.
- فقط نام فایل و metadata نمونه ذخیره می‌شود؛ رمز PDF ماندگار نیست.
- HTML خروجی یک فایل واقعی و مستقل است. Anki بدون exporter واقعی صریحاً unavailable است.
- فرم‌های حساب فعلی API موجود را استفاده می‌کنند؛ Cancel سطح/هدف را پاک نمی‌کند و شکست sign-out پنهان نمی‌شود.
- انتخاب توضیح دقیقاً دو گزینهٔ D31 دارد؛ زبان آزمایشی همچنان انتخاب‌پذیر است و دربارهٔ مقایسه با انگلیسی توضیح داده می‌شود. رضایت جدید تا آمادگی React قابل تیک‌زدن نیست، تا کلیک اولیه گم نشود.

## preview مستقل

`RECALINO_UI_PREVIEW=1` در Vercel production نادیده گرفته می‌شود. guard قبل از session/DB/Auth/API اجرا می‌شود، مسیرهای واقعی API/Auth/dev و روش‌های نوشتن را می‌بندد، root را به Today نمونه می‌برد و health را با mode صریح پاسخ می‌دهد. بدون flag محصول عادی حفظ می‌شود.

deployment فقط Vercel Preview است، با overrideهای synthetic برای متغیرهای سرویس. تنظیمات پروژه، protection و متغیرهای تولید تغییر نمی‌کنند. URL و نتایج نهایی پس از آزمون ثبت می‌شوند.

## نتیجهٔ بررسی نهایی محلی

- `pnpm verify`: همهٔ ۴۰۸ تست در ۴۴ فایل؛ ۳۲۸ unit و ۸۰ integration. lint، TypeScript و ۳۳۵ ماژول/۸۹۱ وابستگی بدون تخلف.
- production build: موفق؛ هر ۴۹ route نمونه به‌صورت static ساخته شد. اسکن bundle مرورگر هیچ secret پیدا نکرد.
- مجموعهٔ مستقل preview: **۱۶۰/۱۶۰ موفق، بدون retry، در ۲٫۱ دقیقه**. ۹۸ نمایش موبایل/دسکتاپ، ۳۶ بررسی axe در روشن/تیره و موبایل/تبلت/دسکتاپ، شمارش ۴۹ صفحه، و ۲۵ سناریوی تعامل/جداسازی.
- ۱۱۶ تصویر نهایی در `artifacts/ui-redesign/complete`: ۹۸ روشن و ۱۸ نمونهٔ تیره. تصاویر Figma، فرم ساخت کلاس، خواندن جزوه روی گوشی و Today دسکتاپ نیز دستی بازبینی شدند.
- محصول واقعی محلی: هر ۹۰ آزمون قابل‌اجرای مرورگر در اجرای کامل و rerunهای هدفمند موفق شد؛ دو بودجهٔ وزن مخصوص production در حالت development اجرا نشد. اجرای نخست ۶ timeout کامپایل سرد و ۳ خطای ARIA داشت؛ rerunها ایرادهای ARIA و consent hydration را آشکار/اصلاح کردند و آزمون تازهٔ Cancel نیز selector صحیح دریافت کرد. این نتیجه به معنی یک اجرای اولیهٔ ۹۲تایی بدون خطا نیست.
- آزمون‌های واقعی حساب/رضایت از Supabase و Postgres محلی استفاده کردند. هیچ migration، reset دیتابیس یا درخواست Google واقعی تازه انجام نشد.
- ورودی action روی URLهای static نیز پیش از lookup با ۴۰۳ رد می‌شود. GET معمول static همچنان session refresh ندارد.
- فرم نمونه پس از بارگذاری state ذخیره‌شده mount می‌شود؛ Refresh متن ویرایش‌شدهٔ transcript را حفظ می‌کند.
- بازبینی پس از commit اولیه، ارجاع منبع در مرور چندکلاسه را اصلاح کرد: لینک هر کارت ابتدا فضای کلاس همان کارت را انتخاب می‌کند. آزمون تازه همراه با ۱۲ آزمون مرتبط یادگیری/کلاس محلی موفق شد؛ مجموعهٔ کامل اکنون ۱۶۱ سناریو دارد.
