# ارسال سادهٔ ایمیل — 2026-10-06

مبنا: درخواست صریح مالک محصول برای حذف کار اضافی فرم Compose، همراه بازبینی تغییرات و commit/push کد. تصویر گزارش‌شده نشان می‌دهد پیام خطای کلی، متن اختیاری «گام بعدی»، تنظیم لینک دکمه و تکمیل هر دو زبان را هم‌زمان اجباری جلوه می‌دهد.

## رفتار مصوب

- مسیر معمول: انتخاب کاربر، انتخاب قالب آماده، بازبینی پیام و تأیید ارسال. نام، ایمیل، لینک اپ و اطلاعات واقعی سهمیه همچنان از سرور حل می‌شوند.
- زبان پیش‌فرض طبق ترجیح گیرنده است؛ قالب‌های آماده هر دو نسخه را دارند. مدیر می‌تواند زبان یا متن هر نسخه را تغییر دهد، اما لازم نیست برای گیرندهٔ فارسی نسخهٔ نامربوط انگلیسی را تکمیل کند.
- متن‌های عمومیِ اختیاری قالب دعوت و تشکر مقدار آمادهٔ محلی‌سازی‌شده دارند. مدیر می‌تواند آن‌ها را جایگزین کند. متن واقعی پاسخ، شرح حادثه یا placeholder سفارشیِ ناشناخته همچنان باید توسط مدیر تکمیل شود؛ پیش‌فرض ساختگی جای دادهٔ واقعی نمی‌گیرد.
- عنوان داخل ایمیل، preheader، دکمه، دلیل داخلی و override متغیرها در تنظیمات اختیاری قرار می‌گیرند. فرم عادی موضوع و متن آماده را واضح نشان می‌دهد.
- خطای ورودی فقط پس از تلاش برای ساخت preview و در محل فیلد مشکل‌دار نمایش داده می‌شود. پیغام کلی چندعلتی حذف می‌شود؛ backend برای زبان‌ها و گیرندگان واقعی اعتبارسنجی نهایی می‌کند.
- پیش‌نمایش دقیق، ظاهر برنددار، تایید جداگانه، snapshot تغییرناپذیر، بررسی consent پشتیبانی، retry امن و محافظت حساب حذف‌شده حفظ می‌شوند. ساخت preview هیچ ایمیلی نمی‌فرستد.

## معیارهای بررسی

1. قالب دعوت بدون واردکردن `next_step_text` برای یک گیرندهٔ فارسی یا انگلیسی preview معتبر می‌سازد.
2. متن آماده و شخصی‌سازی واقعی در preview دیده می‌شوند؛ افزودن متن دلخواه یا تغییر ظاهر قابل انتخاب است.
3. تغییر فرم preview قبلی را باطل می‌کند؛ ارسال فقط نسخهٔ بازبینی‌شده را تایید می‌کند.
4. متغیر سفارشی حل‌نشده و لینک نامعتبر خطای دقیق می‌دهند؛ زبان استفاده‌نشده مانع ارسال گیرندگان دیگر نیست.
5. فرم در فارسی RTL، انگلیسی و موبایل قابل استفاده است و تنظیمات اضافی به‌صورت پیش‌فرض بسته‌اند.
6. بازبینی کد و کامنت‌های در دسترس، بررسی secrets در diff، `pnpm verify`، browser و build پیش از commit/push انجام شوند. نتیجه روی Vercel موجود منتشر و Git branch جاری push شود.

این درخواست مجوز ارسال یک ایمیل واقعی تازه نیست؛ بررسی‌ها از دادهٔ مصنوعی و provider آزمونی استفاده می‌کنند.
