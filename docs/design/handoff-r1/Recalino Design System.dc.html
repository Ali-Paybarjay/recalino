Design system v0.2 · Mint & lime

Built on Nocturne's structure (compact spacing, tonal ramps, themed focus) with the youthful "Mint & lime" colour direction: filled deep-green primary buttons, 14px button / 20px card radii, one lime hero surface per screen. Recalino adds: light-first theme + dark, system fonts only, provenance and status roles, 44px touch targets. Tokens live in recalino/tokens.css as CSS custom properties. Icons: Phosphor (MIT) — bundle as local SVG in the app. No styling library assumed. Handoff: HANDOFF.md.
