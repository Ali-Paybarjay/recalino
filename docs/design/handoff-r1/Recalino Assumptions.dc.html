Assumptions made

  1. Visual base = Nocturne structure, "Mint & lime" colour (option 1c). Light is the default; dark uses the same hues on a deep green ground. Both themes share token names — switch with the theme tweak. The previous indigo set is kept in recalino/archive/.
  2. Fonts: Nocturne specifies Inter; the brief forbids web fonts. Recalino overrides --font-body/--font-heading with a system stack. Don't ship Nocturne's Google Fonts import.
  3. Icons: Phosphor (MIT) instead of Lucide — it is the design system's set. Mockups load it from a CDN for convenience only; the app should bundle @phosphor-icons/react or inline SVGs.
  4. Primary buttons are filled (deep green ink; mint in dark) — a deliberate departure from Nocturne's outline rule, chosen with option 1c. One lime "hero" surface per screen at most (Today's review card); it is not used when the learner is behind on reviews.
  5. "From class" provenance is plum, not teal, so it never reads as the green primary colour.
  6. Prototype timer starts at 2:39:41 so the 2 h 40 min sample class can be demoed; A3/A4 are treated as already accepted.
  7. A2 step 2 (learning language, fixed) is a locked line on the step 3 screen; steps 4 and 5 share one screen. The progress bar still counts 6 steps.
  8. Experimental "side by side" stacks L1 above English under 768px; two columns above.
  9. Allowance units: audio minutes and pages use allowance; photos don't. "Card extras" (Make similar, simpler explanation) use a separate count. Sample numbers only.
  10. Stop confirm is a bottom sheet; audio keeps recording behind it.
  11. No styling library assumed. Tokens are plain CSS custom properties (recalino/tokens.css); components are described by name + props in the design system page.

Open questions

  1. Should the app default to light regardless of OS setting for the pilot, or follow the OS (brief says follow)?
  2. Do photos and HTML pages count against the allowance? If yes, in which unit?
  3. "Ask the pilot operator for more" — in-app message, email, or a mailto link?
  4. Max file sizes and accepted formats for "Not accepted" reasons.
  5. Which languages are "Experimental quality" at launch?
  6. Does "Remembered" in simple mode map to FSRS Good (assumed) or to a derived rating?
