## زبان‌های اول برای آزمون کیفیت (G05، D31 قاعده ۴)

این زبان‌ها پیش از شروع پایلوت آزموده می‌شوند و در صورت قبولی «تأییدشده» می‌شوند. بقیه زبان‌ها طبق D31 قابل انتخاب‌اند، با برچسب «کیفیت آزمایشی».

| زبان | کد | توضیح |
|---|---|---|
| روسی | `ru` | |
| ژاپنی | `ja` | |
| چینی ساده‌شده | `zh-Hans` | زبان‌آموزان از چین اصلی‌اند. چینی سنتی (`zh-Hant`) قابل انتخاب است، ولی آزموده نمی‌شود. |
| فارسی | `fa` | راست‌به‌چپ |
| عربی | `ar` | راست‌به‌چپ |
| اسپانیایی | `es` | زبان‌آموز مکزیکی. توضیح به اسپانیایی عمومی و قابل‌فهم برای اسپانیا و آمریکای لاتین. |
| آلمانی | `de` | |
| ایتالیایی | `it` | |
| رومانیایی | `ro` | |
| اوکراینی | `uk` | |

- **بازبین:** برای هر زبان، یک داوطلب بومی از خود کلاس، حدود ۳۰ دقیقه.
- **نمونه‌ها:** مصنوعی‌اند و داده شخصی ندارند (فرض A5).
- **آستانه قبولی و قالب ثبت نتیجه:** در ماژول EVAL تعیین می‌شود.

## تنظیمات عملیاتی

| مورد | تصمیم | وضعیت |
|---|---|---|
| Spend Management در Vercel | **فقط اعلان** در سقف ۲۰ دلار (۵۰٪، ۷۵٪ و ۱۰۰٪)، **بدون توقف خودکار**. دلیل: تیم Vercel غیر از ریکالینو شش پروژه دیگر دارد و توقف خودکار همه آن‌ها را متوقف می‌کند. ترمز هزینه AI ریکالینو، سقف داخلی خود اپ است (FR-QUOTA-009). | ⏳ کار مالک محصول در داشبورد Vercel |
| نشانی اپراتور برای «Ask the pilot operator for more» | یک نشانی ایمیل تازه مخصوص پایلوت، تا ایمیل شخصی مالک محصول نمایش داده نشود. در پیکربندی سرور (`PILOT_OPERATOR_EMAIL`)، نه در کد یا اسناد. | ⏳ منتظر ساخت نشانی |
| متن‌های حقوقی: شرایط استفاده، اطلاعیه حریم خصوصی، اعلام ۱۸+، رضایت ضبط | تصمیم درباره روش تهیه بعداً. پیش از پایلوت لازم‌اند (G11، Q-ACC-3). | باز |
| مقادیر سهمیه هر زبان‌آموز | پس از اندازه‌گیری هزینه در SPIKE-02 (Q-QUOTA-1، G08) | باز |
| سقف‌های هزینه داخلی AI | پس از SPIKE-02 (Q-QUOTA-2، NFR-12) | باز |

## کارهای مالک محصول پیش از پایلوت

- [ ] تنظیم Spend Management در Vercel: Team Settings → Billing → Spend Management. سقف ۲۰ دلار، فقط اعلان.
- [ ] ساخت نشانی ایمیل مخصوص پایلوت و اعلام آن برای پیکربندی.
- [ ] پیدا کردن یک داوطلب بازبین برای هر یک از ۱۰ زبان.
- [ ] تصمیم درباره روش تهیه متن‌های حقوقی.
