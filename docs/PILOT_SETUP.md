## زبان‌های اول برای آزمون کیفیت (G05، D31 قاعده ۴)

این زبان‌ها پیش از شروع پایلوت آزموده می‌شوند و در صورت قبولی «تأییدشده» می‌شوند. بقیه زبان‌ها طبق D31 قابل انتخاب‌اند، با برچسب «کیفیت آزمایشی».

| زبان | کد | توضیح |
|---|---|---|
| روسی | `ru` | |
| ژاپنی | `ja` | |
| چینی ساده‌شده | `zh-Hans` | زبان‌آموزان از چین اصلی‌اند. چینی سنتی (`zh-Hant`) قابل انتخاب است، ولی آزموده نمی‌شود. |
| فارسی | `fa` | راست‌به‌چپ |
| عربی | `ar` | راست‌به‌چپ |
| اسپانیایی | `es` | زبان‌آموز مکزیکی. توضیح به اسپانیایی عمومی و قابل‌فهم برای اسپانیا و آمریکای لاتین. |
| آلمانی | `de` | |
| ایتالیایی | `it` | |
| رومانیایی | `ro` | |
| اوکراینی | `uk` | |

- **بازبین:** برای هر زبان، یک داوطلب بومی از خود کلاس، حدود ۳۰ دقیقه.
- **زمان:** داوطلب‌ها پس از آماده شدن MVP اولیه و معرفی آن در کلاس انتخاب می‌شوند (مالک محصول، 2026-10-01). تا قبولی در آزمون، هر زبان با برچسب «کیفیت آزمایشی» نمایش داده می‌شود (D31، قاعده ۳).
- **نمونه‌ها:** مصنوعی‌اند و داده شخصی ندارند (فرض A5).
- **آستانه قبولی و قالب ثبت نتیجه:** در ماژول EVAL تعیین می‌شود.
